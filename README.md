# ShoeCare

ShoeCare is a modern shoe care and management platform designed to provide users with an easy way to explore shoe care products, manage services, and maintain their footwear. The platform focuses on delivering a clean, responsive, and user-friendly experience with a modern UI and efficient state management.

Built with modern frontend technologies including **Next.js, Tailwind CSS, Shadcn UI, and Zustand**, ShoeCare provides a scalable and maintainable architecture for future improvements.


## Features

-  Modern and responsive user interface
-  Browse shoe care products and services
-  Product search and filtering
-  Shopping cart functionality
-  User authentication support
-  Fully responsive design
-  Fast performance with Next.js
-  Reusable UI components with Shadcn UI
-  Global state management using Zustand


##  Tech Stack

### Frontend

- **Next.js** - React framework for production-ready applications
- **React** - Component-based UI development
- **TypeScript** - Type-safe JavaScript development
- **Tailwind CSS** - Utility-first CSS framework
- **Shadcn UI** - Accessible and customizable UI components
- **Zustand** - Lightweight state management
- **React Icons** - Popular icon library for React applications
- **Lucide React** - Modern icon library used with Shadcn UI

### Development Tools

- **ESLint** - Code quality and consistency
- **Prettier** - Code formatting
- **Git & GitHub** - Version control
